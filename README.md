## Como eu trabalho

- **Escopo por escrito** e entregas em etapas, com o cliente vendo o sistema funcionar cedo.
- **IA onde ela ajuda, código onde precisa ser confiável**: o modelo extrai e escreve; regras
  testáveis decidem.
- **Segurança e LGPD desde o início**: segredos fora do código, menor permissão possível, dados
  pessoais tratados como risco.
- **Entrega documentada**: README, decisões registradas e instruções de operação.
